# MATLAB Companion icon

Created: 2026-09-15. This original mark represents a numerical curve connecting
an initial condition to an observed data point. It is independent of MathWorks
and university branding.

- Midnight navy tile, cyan curve and warm amber point/axis accent.
- PNG master: `adapters/codex/matlab-companion/assets/icon.png` (1254 × 1254).
- Windows ICO export: `adapters/codex/matlab-companion/assets/icon.ico`, with
  16, 32, 48 and 256 pixel representations of the same generated artwork.
- The Codex manifest uses the PNG for composer and light/dark logo slots.
- The current-device Start-menu shortcut uses the ICO. The existing Tk window
  itself was not modified or visually accepted as part of this asset update.

The master was created with the built-in image generation tool. The ICO is a
format/size export of that artwork; the master remains unchanged. Assets are
distributed with this repository's MIT licence. Do not imply vendor endorsement.

[scoped upgrade receipt](../verification/local-upgrade-v0.1.0-alpha.2.json).
